# Soundarya Hotel — Demo Website

A single-page demo website (`index.html`, self-contained, no build step) built for **Soundarya Hotel Boarding And Lodging**, T. Dasarahalli, Bengaluru, as part of Arya's website + AI video agency work.

- The rooms, tariffs and details shown on the page are **sample placeholders**, clearly labelled on the page itself — they are to be replaced with the hotel's actual rooms, photos and rates once the owner confirms them.
- The rating shown (4,500+ ratings on Justdial) is from the hotel's public Justdial listing, researched 31 Oct 2026.
- The page leads with a "Book Direct" message: guests can enquire and book on WhatsApp instead of through an OTA that takes commission.
- Photos are royalty-free stock images, credited in the page footer.

**No one at the hotel has been contacted about this demo yet.**
